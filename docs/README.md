# Documentation

## Why this directory exists

`docs/` preserves architectural intent, public contract design, and delivery direction that cannot be communicated by code structure alone.

## What belongs here

Architecture decisions, API principles and specifications, roadmaps, operational guides, security models, and other durable engineering documentation belong here.

## What does not belong here

Source code, generated documentation, transient planning notes, vendor marketing material, and secrets do not belong here.
