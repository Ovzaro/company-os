# Tools

## Why this directory exists

`tools/` defines capabilities a digital employee may invoke and the controls around their execution.

## What belongs here

Tool contracts, schemas, discovery, authorization, execution boundaries, results, audit metadata, and tool adapters belong here.

## What does not belong here

Unrestricted arbitrary execution, provider-specific function-call payloads as domain contracts, channel commands, secrets, and unrelated developer scripts do not belong here.
