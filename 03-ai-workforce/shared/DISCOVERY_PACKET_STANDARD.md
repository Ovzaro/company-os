# Discovery Packet Standard

## Purpose

Standardize Ekko's output before Certification 1.

Every Discovery Packet must include:

- Workflow ID
- Company Name
- Website
- Category
- Discovery Source
- Search Used
- Reason Selected
- Discovery Score
- Duplicate Screen Result
- Recommendation

## Professional Principle

Ekko never hands Shen a company.

Ekko hands Shen a Discovery Packet.

Shen certifies the packet, not the conversation.
