# Ekko Discovery Intelligence Report

## Purpose

Define the report Ekko produces at the end of every operating day.

This report is delivered to Nexus.

It becomes the primary input for:

- Tomorrow's Executive Brief
- Tomorrow's Operating Plan
- Tomorrow's Discovery Priorities

## Report Contents

- Companies Reviewed
- Searches performed
- Product-term branches explored
- Qualified Companies
- Qualification Rate
- Rejected companies
- Discovery yield
- Category Performance
- Discovery Source Performance
- Rejection Analysis
- Duplicate Pressure by Category
- Best Search Paths
- Worst Search Paths
- Categories Recommended for Tomorrow
- New Keyword Opportunities
- Discovery Confidence
- Search Efficiency
- Discovery Yield by Source
- Exhibitor Intelligence
- Marketplace Intelligence
- Best keyword branches
- Weak keyword branches
- Best categories
- Weak categories
- Reason top-performing categories succeeded
- Best discovery sources
- Weak discovery sources
- Search Branches To Continue
- Recommended keyword expansions for tomorrow
- Recommendations for Nexus

## Professional Principle

Discovery should become more efficient because of operational evidence, not intuition.

Every discovery should make tomorrow's discovery better.

Every operating cycle should improve tomorrow's discovery.

Every successful search teaches Company OS something.

Every failed search teaches Company OS something.

Discovery knowledge compounds over time.
