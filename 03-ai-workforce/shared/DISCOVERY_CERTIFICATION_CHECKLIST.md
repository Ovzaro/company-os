# Discovery Certification Checklist

## Purpose

Define the objective acceptance criteria for Discovery Certification.

PASS only if ALL required items are present.

## Required

☐ Workflow ID

☐ Company Name

☐ Website

☐ Category

☐ Discovery Source

☐ Search Used

☐ Reason Selected

☐ Discovery Score

☐ Duplicate Screen Result

☐ Recommendation

## PASS

Every required item exists.

## FAIL

If any required item is missing.

## Return To

Ekko

## Professional Principle

Certification verifies completeness.

Certification does not judge quality.
