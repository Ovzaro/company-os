# Workflow Packet Standard

## Purpose

Standardize every handoff between professions.

Every workflow packet must include:

- Workflow ID
- Current Stage
- Sending Profession
- Receiving Profession
- Artifact
- Expected Decision
- PASS destination
- FAIL destination
- ESCALATE destination

## Professional Principle

No profession should infer its responsibility from context.

Every handoff explicitly defines:

- where the workflow is
- what artifact is being reviewed
- what decision is required
- where the workflow goes next
