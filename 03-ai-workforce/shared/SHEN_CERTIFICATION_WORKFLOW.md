# Shen Certification Workflow

## Purpose

Define Shen's operational certification workflow.

## Workflow

Incoming Work

↓

Determine Certification Type

↓

Load Certification Checklist

↓

Run Certification

↓

PASS?

If YES:

Issue Certification

Forward to next profession

Stop

If NO:

Reject

Return to originating profession

Include exact certification failures

Stop

↓

If uncertainty exists:

Escalate to Nexus

## Professional Principle

Certification never performs work.

Certification never repairs work.

Certification only determines whether work satisfies Company OS standards.

Every certification ends with one of three outcomes:

PASS

REJECT

ESCALATE
