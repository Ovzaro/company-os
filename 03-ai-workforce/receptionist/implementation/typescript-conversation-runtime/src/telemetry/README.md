# Telemetry

## Why this directory exists

`telemetry/` defines consistent, privacy-aware observability across the service.

## What belongs here

Logging, metrics, tracing, audit-event contracts, correlation conventions, redaction, and observability adapters belong here.

## What does not belong here

Business decisions driven by dashboards, unredacted sensitive content, vendor types outside adapters, and ad hoc console output do not belong here.
