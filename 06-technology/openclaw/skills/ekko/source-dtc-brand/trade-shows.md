# Trade Shows — mining exhibitor lists for DTC leads

Trade shows publish **exhibitor directories** — concentrated lists of brands in a single category.
Mine them: find the show → open its exhibitor directory → harvest brand names + sites → qualify each
through the gate. Jacob doesn't have a fixed show list; Ekko finds them with the searches below.

## ⚠️ Read first — trade shows are B2B
Exhibitor lists are **full of manufacturers, OEM/private-label producers, wholesalers, distributors,
ingredient suppliers, and sales reps** — all **auto-SKIP** for us. You're mining for the subset that
are **true consumer DTC brands** selling their own product from their own site. Expect a low hit-rate
and qualify hard. The directory is a lead *source*, never a pass.

## How to find shows (search patterns)
Run these discovery queries in **Google through the shared `openclaw` Chrome profile**:

- `{lane} trade show exhibitor list`
- `{lane} expo exhibitor directory`
- `"exhibitor list" {category} expo`
- `{show name} exhibitors A-Z`
- `{show name} exhibitor directory`
- Past editions work too (archived brands are still valid): `{show} 2025 exhibitor list`

## Workflow
1. **Find the show + its exhibitor directory** (often filterable by category/product type).
2. **Harvest** exhibitor brand names + website links — work every page, don't stop at page one.
3. For each brand, **open its own site and run the full gate** (true DTC, live/functional checkout,
   no manufacturer/wholesaler). Skip the B2B majority.
4. Avoid obvious duplicate run-sheet entries, then pass qualified brands to the run sheet with the
   celeb pick. Do **not** perform HubSpot/CRM de-dupe — Viktor owns HubSpot/CRM de-dupe.

## Make it self-improving
Cross-reference with Heimerdinger's read: if a show's brands convert, promote it to a proven channel
and log it; if a directory is mostly B2B noise, note it and don't waste a future batch on it.
