# Search Queries — Beauty & Personal Care lane

Keyword vocabulary + query templates for sourcing **true-DTC beauty/skincare/haircare brands**. This
is the *Beauty & Personal Care* lane of Ekko's playbook. Other lanes (pet, home, wellness, outdoor,
kids) get their own banks below as they're added.

## How to use this (read before searching)

Jacob's Google method is a **three-word comma query**:

```
{ingredient}, {product form}, {descriptor}
```

Examples: `niacinamide, serum, clean` · `niacinamide, cream, natural` · `vitamin E, capsule, supplement`

- **Rotate the descriptor (3rd slot) to get different SERPs.** The interchangeable descriptor is what
  surfaces fresh brands — run the same ingredient × form against several descriptors (see the
  Descriptor bank in each lane). Also vary ingredient × form, and lean toward what Heimerdinger's
  last-24h read says is converting.
- **Work every result.** Go through every organic result the search returns — open each candidate's
  own site and run the gate. Don't stop at the first page.
- **Cross-channel.** The same triplets feed **Google Shopping** and the **Meta Ad Library** (a brand
  advertising a "bakuchiol serum" is a live DTC spender).
- **Goal = the brand's own DTC site.** A result is just a breadcrumb. Land on the brand's own branded
  store (working checkout) and run the full qualification gate before adding. Marketplace/retailer
  listings (Amazon/Walmart/Sephora) are discovery only, never the lead.
- **Optional noise-cut:** if a SERP is clogged with encyclopedias/suppliers, append negative keywords
  (below) to thin it before you start opening results — but the gate is the real filter.
- **Improve the method.** When a new query pattern, source, descriptor, or negative-keyword set
  produces real Sales-worthy opportunities, tag the `source_channel` and note the lesson so
  Heimerdinger can promote it. If it produces noise, retire it.

## Shopping-intent terms (pick one+)
`shop` · `buy` · `"add to cart"` · `"shop now"` · `store` · `"free shipping"`

Use these modifiers across every lane when Google returns mostly articles, marketplaces, or suppliers.
The goal is always the brand's **own DTC website** with a working cart/checkout — Amazon, Walmart,
Etsy, retailer, marketplace, and review/listicle pages are discovery breadcrumbs only.

## Ingredient vocabulary (compose queries from these)

Grouped by function. Use the ingredient term inside the template above with a fitting product type.

**Cleansing agents (surfactants):** sodium lauryl sulfate, sodium laureth sulfate, cocamidopropyl
betaine, decyl glucoside, sodium cocoyl isethionate.

**Humectants (pull water into skin):** glycerin, hyaluronic acid (sodium hyaluronate), propylene
glycol, butylene glycol, urea, sorbitol, panthenol (pro-vitamin B5), honey, aloe vera.

**Emollients (soften and smooth):** squalane, jojoba oil, shea butter, cocoa butter, lanolin, mineral
oil, petrolatum, dimethicone, cyclomethicone, cetyl alcohol, stearyl alcohol, isopropyl myristate.

**Occlusives (seal in moisture):** petrolatum, beeswax, lanolin, dimethicone, mineral oil, carnauba wax.

**Exfoliants:** AHAs — glycolic acid, lactic acid, mandelic acid, citric acid, malic acid. BHAs —
salicylic acid. PHAs — gluconolactone, lactobionic acid. Physical — sugar scrub, jojoba beads, rice
powder.

**Antioxidants:** vitamin C (ascorbic acid, sodium ascorbyl phosphate, magnesium ascorbyl phosphate,
tetrahexyldecyl ascorbate), vitamin E (tocopherol), ferulic acid, resveratrol, green tea extract
(EGCG), coenzyme Q10, niacinamide.

**Retinoids:** retinol, retinal (retinaldehyde), retinyl palmitate, adapalene, tretinoin, bakuchiol
(plant-based alternative).

**Skin-brightening / pigmentation:** hydroquinone, kojic acid, arbutin, azelaic acid, tranexamic acid,
licorice root extract, alpha arbutin.

**Peptides:** matrixyl (palmitoyl pentapeptide-4), copper peptides, argireline (acetyl hexapeptide-8),
palmitoyl tripeptide-1.

**Ceramides and barrier support:** ceramides (NP, AP, EOP), cholesterol, fatty acids (linoleic, oleic,
stearic), phytosphingosine.

**Sunscreens:** chemical — avobenzone, octinoxate, octisalate, homosalate, octocrylene, oxybenzone.
Mineral — zinc oxide, titanium dioxide.

**Soothing / anti-inflammatory:** centella asiatica (cica, madecassoside), allantoin, bisabolol,
chamomile, colloidal oatmeal, green tea, licorice extract.

**Preservatives:** phenoxyethanol, parabens (methyl-, propyl-, ethyl-), benzyl alcohol, sodium
benzoate, potassium sorbate, ethylhexylglycerin, caprylyl glycol.

**Emulsifiers and stabilizers:** cetearyl alcohol, glyceryl stearate, PEG-100 stearate, polysorbate
20/60/80, lecithin, xanthan gum, carbomer.

**pH adjusters:** citric acid, lactic acid, sodium hydroxide, triethanolamine.

**Fragrance and sensory:** parfum/fragrance, essential oils (lavender, rose, tea tree), menthol.

**Solvents / base:** water (aqua), ethanol, denatured alcohol, glycerin.

> Note: some of these (preservatives, emulsifiers, pH adjusters, solvents) are *formulation* terms that
> rarely appear in consumer marketing — they're weak search hooks on their own. Lead with the
> **hero/active** ingredients (actives, exfoliants, antioxidants, retinoids, brighteners, peptides,
> sunscreens, soothing) paired with a product type; use the base/formulation terms only as secondary
> filters.

# Search Queries — Health & Wellness / Supplements lane (LEAD LANE)

Ekko's primary lane. Same method as Beauty: compose `{ingredient} + {product form} + {shopping intent}
+ {negative keywords}`, land on the brand's own DTC store, then run the gate. **No-Go screening is
critical here** — this lane has the most No-Go traps (CBD/kratom/kava, hormones, sexual health,
disease-treatment claims, embarrassing products). Check the candidate against the celeb's No-Go list
in `AGENTS.md` before assigning.

## Site-scoped search (inside specific platforms)

The same ingredient/product keywords work *inside* a platform's own search bar. The platform is just a
discovery surface — **the lead is always the brand's own DTC site**, reached by clicking through.

### Amazon & Walmart (keep it simple)
- In the site search bar, type `{keyword} {product type}` — e.g. `niacinamide cream`,
  `magnesium supplement`, `collagen powder`.
- Scan the product results; on a promising product, open the listing and find the **brand/seller name**.
- Search that brand on Google → land on its **own branded site** → run the gate. A brand that **only**
  sells on Amazon/Walmart with no real DTC site of its own **fails the gate**.

### Meta Ad Library (Instagram + Facebook ads) — secondary / explore channel
A brand running active paid ads is by definition a **live DTC spender** — a strong lead signal. But
the surface is noisy, so treat it as secondary and lean in only if it converts (explore/exploit).
1. Go to **facebook.com/ads/library** → set **Country = United States**, **Ad category = All ads**.
2. Search a product keyword the same way: `{keyword} {product type}` (e.g. `collagen serum`,
   `magnesium gummies`).
3. Scan for advertisers running **multiple active ads** — real spend, not a one-off. Note the brand.
4. Click an ad → open the **landing page** → confirm it's the brand's **own DTC site** → run the gate.
5. Strongest signal: many active creatives + a clean DTC funnel (Shopify-style cart/checkout).
